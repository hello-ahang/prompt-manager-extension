# Prompt Manager

一个轻量级 Chrome 扩展，用于管理和快速注入系统提示词到 AI Chat 输入框。

## 痛点与场景

使用 ChatGPT、Claude、通义千问等 AI 对话工具时，你是否遇到过这些问题：

- **重复粘贴**：每次新对话都要重新找到并粘贴同一段系统提示词，效率极低
- **提示词散落**：提示词存在备忘录、笔记、文档各处，找起来费时费力
- **无法复用**：精心调试好的提示词，换个浏览器或设备就丢了
- **切换成本高**：不同任务需要不同的提示词（写代码、翻译、写作），来回切换很麻烦

### 典型使用场景

- **开发者**：把「代码审查专家」「架构设计顾问」等角色提示词存好，一键注入，立刻进入专业对话
- **产品/运营**：管理「竞品分析」「文案润色」「数据解读」等常用提示词，随取随用
- **翻译/写作**：按语种、风格分组管理翻译和写作提示词，告别反复粘贴
- **团队协作**：通过导入/导出功能，将团队最佳提示词集合共享给同事

## 功能

- **提示词管理**：新增、编辑、删除系统提示词
- **分组管理**：按分组组织提示词，支持新建分组
- **关键词搜索**：快速搜索提示词标题和内容
- **一键注入**：点击提示词即可注入到当前页面的 AI Chat 输入框
- **导入/导出**：一键导出所有提示词为 JSON 文件，支持导入恢复数据
- **全域名支持**：支持在任意网站上注入，包括 iframe 内的输入框

## 注入格式

点击提示词后，会将以下内容注入到输入框：

```
--用户输入：

--系统提示词：
<提示词内容>
```

## 技术栈

- Chrome Extension Manifest V3
- TypeScript + React
- Vite + @crxjs/vite-plugin
- TailwindCSS

```bash
npm run build
```

## 安装使用

本项目使用 TypeScript + React 开发，浏览器无法直接加载源码，需要先构建。

1. 从 GitHub 下载或 `git clone` 本项目
2. 进入项目目录，运行 `npm install` 安装依赖
3. 运行 `npm run build` 构建项目，生成 `dist` 目录
4. 打开 `chrome://extensions/`，开启右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"，选择项目中的 `dist` 目录
6. 浏览器工具栏出现插件图标即安装成功

## 数据说明

**所有提示词数据仅存储在浏览器本地**（`chrome.storage.local`），不会上传到任何服务器，也不会写入项目文件中。卸载插件或清除浏览器数据会导致数据丢失，建议定期导出备份。

## 数据备份与迁移

- 点击插件底部的 **导出** 按钮，下载 JSON 备份文件
- 切换浏览器或重装插件后，点击 **导入** 按钮选择备份文件即可恢复数据
